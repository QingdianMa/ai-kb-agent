# 知识库语料目录

**这个目录里的文件会被导入知识库，访客提问时智能助理会检索它们。**

所以规则只有一条：**只放可以对外公开的资料。**

## 该放什么

| 文件 | 内容 |
|---|---|
| 实验室简介 | 名称、依托单位、总体定位 |
| 研究方向 | 各方向的介绍、关键技术、应用场景 |
| 团队成员 | 姓名、身份、研究方向、联系方式 |
| 研究成果 | 代表性论文、专利、项目、获奖 |
| 招生信息 | 招收方向、报考要求、联系方式 |
| 常见问题 | 高频问题的标准答案 |

## 不要放什么

- 未发表的论文、在投稿件
- 内部会议纪要、项目申报材料
- 学生的个人隐私信息（身份证、电话、成绩）
- 有保密要求的合作项目资料
- `docs/` 目录里的开发文档

## 格式建议

- 用 `.md`（Markdown）或 `.txt`，也支持 `.pdf` 和 `.docx`
- **用标题分节**（`## 一、xxx`），切分时会把章节名带进片段，检索更准
- 讲清楚具体事实和数字，避免空话
- **扫描件不行**——图片型 PDF 没有文字层，解析出来是空的

## 更新方式

1. 在这个目录增删改文件
2. 后台点「同步知识库目录」
3. 已存在的文件会按内容哈希自动跳过，只处理新增和改动过的
